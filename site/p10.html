📷 P10 — Upload Foto

Pertemuan 10 menambahkan upload foto ke CRUD mahasiswa dengan helper aman.

TODO / Pekerjaan Inti

  • P10-1: form.php dan edit.php → lengkapi enctype="multipart/form-data", input foto. Jangan hapus field csrf.
  • P10-2: tambah.php → ganti nilai sementara $foto dengan simpanFoto() dari helper foto.php.
  • P10-3: ubah.php → isi $fotoBaru dari simpanFoto(), pertahankan cabang null, UPDATE, hapus foto lama hanya setelah berhasil.

Aturan Helper

  • Maksimal 1 MB.
  • MIME dibaca dari isi file dengan finfo, bukan dari browser.
  • Struktur gambar diperiksa dengan getimagesize().
  • Nama file acak (32 hex + ekstensi).
  • hapusFoto() hanya menerima pola nama yang dibuat server.

Urutan Aman

  1. Create: boleh tanpa foto.
  2. Edit tanpa foto: kolom foto tetap.
  3. Foto lama dihapus hanya setelah UPDATE berhasil.
  4. Foto baru dibersihkan bila SQL gagal.
// contoh pemanggilan
$foto = simpanFoto($_FILES['foto'] ?? []);
Folder uploads/ publik adalah kompromi latihan. Apache .htaccess menolak skrip, tetapi PHP built-in server tidak menerapkan .htaccess.
