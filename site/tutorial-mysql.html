🗄️ Tutorial MySQL (XAMPP)

← Kembali

1. Jalankan MySQL

Buka XAMPP Control Panel → Start Apache & MySQL.

2. Import database.sql

  • Buka phpMyAdmin: http://localhost/phpmyadmin
  • Tab Import → pilih database.sql → Go.

3. Port MySQL

  • Default XAMPP: 3306
  • Paket lab: 3307

Sesuaikan di koneksi.php.

4. Cek Koneksi

Buka cek-koneksi.php → harus "Koneksi database MySQL berhasil!".

5. Troubleshooting

  • Access denied → cek user/password.
  • Unknown database → import ulang.
  • Port bentrok → ubah port di my.ini dan koneksi.php.
  • pdo_mysql not found → aktifkan extension di php.ini.
