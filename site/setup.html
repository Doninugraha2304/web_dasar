⚙️ Setup & Menjalankan (Monorepo)

1

Clone / Pull

git clone https://github.com/Doninugraha2304/web_dasar.git
cd web_dasar

# update
git pull origin main
2

Struktur Monorepo

web_dasar/
├── p09/   (Pertemuan 9: Login Session + CRUD)
├── p10/   (Pertemuan 10: Upload Foto)
├── docs/
├── site/  (frontend statis)
└── vercel.json
3

Setup Database MySQL

Import file SQL sesuai modul:

  • P09: p09/database.sql → DB sia_praktikum
  • P10: p10/database.sql → DB sia_praktikum_p10

Via phpMyAdmin: tab Import → pilih file → Go.

4

Konfigurasi koneksi.php

Sesuaikan port MySQL (XAMPP: 3306, paket lab: 3307) pada:

  • p09/koneksi.php
  • p10/koneksi.php
5

Menjalankan P09

cd p09/public
php -S localhost:8000

Buka http://localhost:8000/daftar-akun.php

6

Menjalankan P10

cd p10/public
php -S localhost:8002

Buka http://localhost:8002/daftar-akun.php

7

Menjalankan via XAMPP

Copy repo ke htdocs/web_dasar, lalu akses:

  • P09: http://localhost/web_dasar/p09/public/daftar-akun.php
  • P10: http://localhost/web_dasar/p10/public/daftar-akun.php
8

Materi & Dokumentasi

  • P09 materi: p09/public/dashboard_materi.php
  • P10 materi: p10/public/dashboard_materi.php
  • Teori interaktif: site/presentasi.html
  • Tutorial MySQL: docs/TUTORIAL_MYSQL.md
  • Tutorial XAMPP: docs/TUTORIAL_XAMPP.md
Tips: Gunakan port berbeda untuk P09 dan P10 agar tidak bentrok.
