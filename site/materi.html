📖 Materi P09: Login Session

← Kembali

1. Konsep

  • Autentikasi: verifikasi identitas pengguna.
  • Session: menyimpan status login di server.
  • Password: disimpan sebagai hash (bcrypt) via password_hash().

2. Alur

  1. Register akun → hash password → simpan ke tabel pengguna.
  2. Login → password_verify() → session_regenerate_id() → simpan $_SESSION['pengguna'].
  3. Akses halaman data → cek session (wajib-login).
  4. Logout → hapus session & cookie.

3. Keamanan

  • Prepared statement (PDO) → cegah SQL injection.
  • CSRF token pada form POST.
  • Session cookie: httponly, samesite=Lax.
  • Logout hanya via POST bertoken.

4. Struktur Tabel

CREATE TABLE pengguna (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  username VARCHAR(30) NOT NULL UNIQUE,
  nama VARCHAR(100) NOT NULL,
  password_hash VARCHAR(255) NOT NULL,
  dibuat DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE mahasiswa (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  nama VARCHAR(100) NOT NULL,
  nim VARCHAR(20) NOT NULL UNIQUE,
  email VARCHAR(254) NOT NULL
);

5. File Penting

  • koneksi.php - koneksi PDO MySQL.
  • keamanan.php - session + CSRF.
  • login.php - login.
  • daftar-akun.php - register.
  • wajib-login.php - proteksi halaman.
  • form.php - daftar + tambah mahasiswa.
  • tambah.php / ubah.php / hapus.php - CRUD.
