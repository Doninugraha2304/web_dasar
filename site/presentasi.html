Checklist Keamanan

Berita & CVE Terkait Upload/Keamanan

Contoh insiden nyata: celah upload file sering menjadi jalan masuk RCE (Remote Code Execution). Selalu cek NVD/CVE terbaru sebelum produksi.

CVE-2020-25213

WP File Manager: unauthenticated arbitrary file upload → RCE. Pelajaran: jangan percaya nama/ekstensi file dari user.

CVE-2021-24145

Plugin WordPress dengan upload tidak aman. Pelajaran: validasi server-side wajib, bukan hanya browser.

CVE-2024-4577

PHP CGI argument injection (RCE). Pelajaran: keamanan PHP tidak hanya upload, tapi juga konfigurasi server.

Dampak Jika Upload Tidak Aman

  • Web shell tersimpan di server → attacker bisa eksekusi perintah.
  • Deface / pencurian data / ransomware.
  • Server dipakai botnet / crypto miner.
  • Kehilangan reputasi dan kepercayaan pengguna.

Kebiasaan Aman (Checklist)

  • Validasi MIME dari isi file (finfo), bukan ekstensi.
  • Batasi ukuran dan jenis file.
  • Nama file acak, jangan pakai nama asli.
  • Simpan di luar webroot bila memungkinkan.
  • Tolak eksekusi skrip di folder upload (.htaccess / Nginx rules).
  • Update PHP, framework, plugin, dan OS secara rutin.
  • Monitoring log dan backup.
Sumber rujukan: OWASP File Upload Cheat Sheet, PHP Manual (Handling file uploads, finfo, move_uploaded_file), NVD/CVE database.
