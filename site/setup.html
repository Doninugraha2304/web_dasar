⚙️ Setup & Menjalankan Aplikasi

← Kembali

1. Clone / Pull

git clone https://github.com/Doninugraha2304/web_dasar.git
cd web_dasar

# update
git pull origin main

2. Setup Database MySQL

  • Jalankan Apache + MySQL (XAMPP).
  • Buka phpMyAdmin: http://localhost/phpmyadmin
  • Tab Import → pilih database.sql → Go.

3. Konfigurasi koneksi.php

$host = '127.0.0.1';
$port = 3306;        // XAMPP: 3306 | Lab: 3307
$database = 'sia_praktikum';
$userDb = 'root';
$passwordDb = '';

4. Menjalankan

Cara A (XAMPP): copy folder ke htdocs, lalu buka http://localhost/web_dasar/public/login.php

Cara B (PHP built-in):

cd public
php -S localhost:8000

Buka http://localhost:8000

5. Alur Penggunaan

  1. Daftar akun di daftar-akun.php.
  2. Login di login.php.
  3. Kelola data mahasiswa di form.php.
  4. Logout via tombol Keluar.
